# Inventory Planning & Replenishment Decision Support (FMCG)

End-to-end inventory decision-support system (FMCG / HUL-like use case) including:
- Demand forecasting (baseline vs XGBoost)
- Safety Stock, Reorder Point (ROP), EOQ calculations
- Stockout early warning (within lead time)
- Reorder recommendations (action + quantity)
- Overstock / slow-moving monitoring
- Supplier lead-time & reliability analysis
- What-if scenario analysis (Power BI)

## Files
- `/outputs/` : decision tables and scenario results (CSV)
- `/powerbi/` : Power BI dashboard file (PBIX) (if included)

Note: Uses synthetic data for demonstration (no confidential company data).
